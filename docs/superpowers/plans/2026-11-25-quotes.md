# Quote Requests Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A public quote form at `/devis` (kmk-public look, three languages, photos, 10/hour/IP) feeding an internal
Quotes area for admins (conversation history, replies by email), with a shared task, an Agenda item, a notification
email and Web Push on each new request, plus company-wide System settings.

**Architecture:** New backend packages `app/quotes/` (public intake, arrival side effects, internal API),
`app/push/` (subscriptions and sending) and a module `app/system_settings.py` (key/value settings in the database).
One hand-written migration `0013`. The frontend gets a second Vite entry (`quote.html` → `src/public-quote/`) that
shares nothing with the internal app but the build, and a new `src/quotes/` area inside the signed-in app.

**Tech Stack:** FastAPI, SQLAlchemy 2, Postgres, Alembic (explicit SQL), `pywebpush` (new), React + Vite +
TanStack Query + react-i18next, vitest, Caddy.

**Spec:** `docs/superpowers/specs/2026-11-25-quotes-design.md`

## Global Constraints

- Public form: fr-CA default, en-CA, pt-BR; stored `locale` values are exactly `fr-CA`, `en-CA`, `pt-BR`.
- Rate limit: **10 started requests per hour per IP** (`ratelimit.ip_key`, IPv6 per /64); no global limit; answer `429 {"error":"rate_limited"}`.
- Free text: at most **2000 words** (words = `len(text.split())`, frontend `text.trim().split(/\s+/)`) and at most **20 000 characters**; required for `commercial`, optional for `airbnb`.
- Photos: at most **10** per request, each at most **8 MiB** (`8 * 1024 * 1024`), types `image/jpeg`, `image/png`, `image/webp`, `image/heic` detected by bytes (`documents.files.detect_document`).
- Drafts expire **2 hours** after creation; uploads refused with `503 {"error":"busy"}` while drafts hold more than **300 MB** (`300 * 1024 * 1024`) of photos.
- Reference: `f"D-{id:04d}"`.
- Deadline: `submitted_at + 24h`; task `due_date` = company-time-zone (`America/Toronto`) date of the deadline; Agenda item at the deadline, 30 minutes, one reminder 2 hours before.
- Task and event titles carry **no customer data**: `Quote D-0042 · Airbnb · Québec` / `Quote deadline D-0042 · Airbnb · Québec` (French labels when generated: type labels `Airbnb` / `Commercial`, city = the `city` field).
- Quotes visible only to `admin` and `superadmin`; delete by `superadmin` only; System settings by `superadmin` only.
- No customer email, phone or free text in audit rows, logs, push payloads or the notification email.
- Every protected route uses `guard()`; public routes are listed in `tests/test_mfa_guard.py::PUBLIC`.
- Audit with `audit.log(...)` only; migrations as explicit SQL; `app/models.py` kept in step; tests first.
- New internal strings in all three locale files with prefix `quote` (push/settings strings: `push`, `sys`); public form strings in `src/public-quote/strings.ts` with a key-set test.
- New API settings go into `api.environment` in `deploy/docker-compose.yml`.
- Raise the minor version in `frontend/package.json` and `backend/pyproject.toml`.
- Commit after each task; messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Submitting twice** (double click, retry after a timeout): the second `submit` returns the same reference and creates no second task, event, email or push.
2. **Photo upload with a wrong, expired or already-submitted token**: refused (`404 not_found`), nothing stored; a valid token for draft A cannot add photos to draft B.
3. **Exactly 2000 words / 2001 words, and 20 000 characters of accented text**: 2000 accepted, 2001 refused with `422 {"error":"too_long"}`; the accented body passes Caddy's 256 KB cap.
4. **Reply sent while the sender setting is empty, or the provider fails**: empty sender → `409 sender_not_configured`, nothing stored; provider failure → message stored `failed`, status and task unchanged until a successful retry.
5. **Notification email or push failing at arrival**: the submit still answers 200 with the reference; the request, task and event are committed.
